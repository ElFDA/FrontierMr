    How to use it

    A theme is a folder in /media/fat/frontier/themes/<name>/ with theme.ini (16:9), optionally theme_43.ini (CRT and 4:3 screens), detail.ini / detail_43.ini (detail screen), screensaver.ini / screensaver_43.ini (screensaver: random games after some time without keys), loading.ini / loading_43.ini (loading screen, while a core loads the game: ${progress}, type=bar; without them the ones of the simple theme are used), pictures and TTF fonts. The active theme is chosen in /media/fat/frontier/frontier.ini (theme=<name>).

    • Open folder: with Chrome/Edge the theme is saved directly in the folder; with other browsers use Download .ini and copy the file.
    • Variant chooses the file to edit; Make 4:3, Make detail and Make screensaver make the missing ones from the current one.
    • Import .ini loads .ini files of a theme into the editor (e.g. those of another theme, into the open folder whose pictures and fonts are used): theme.ini, theme_43.ini, detail.ini, detail_43.ini, screensaver.ini, screensaver_43.ini by their name, any other name into the current variant.
    • Drag an element to move it, the handles to resize it; arrows = 1 px, Shift+arrows = 10 px; Shift while dragging = no grid.
    • Coordinates in "base" units (e.g. 1280×720), scaled to the real screen. size of the texts = font height in base px, as in CSS.
    • The preview is approximate: to see it for real copy the theme to the MiSTer (tools/fe/theme_push.sh) and press F5 in Frontier, or use tools/fe/preview/preview.sh on a PC.
    • Animations (fades, scrolling, frames, video) are not animated here.
